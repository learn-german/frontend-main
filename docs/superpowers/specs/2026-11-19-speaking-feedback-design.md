# Optional speaking feedback audio

Source: Notion 40592cf518d880979debf179d3ceb9a2 and user-downloaded Downloads/deutschselbst-speaking-feedback-ui.zip README/reference.

Preserve existing learner submission flow and score 0–100 including 0; written comment stays optional and existing 10000-character cap. Add optional teacher audio feedback per submission. Admin may select/preview/replace/remove file locally; cancel leaves saved score/comment/file unchanged. Save performs upload then one database grade update; only afterwards clean up old unreferenced audio. Upload/DB errors must not delete attached audio; cleanup errors after successful save are warnings. A click on learner name opens their submission history/files. Learners see correct attempt's grade/text/audio with separate labels for original/feedback audio. Missing audio hides that block. Preserve all previous attempts.

Reuse existing private speaking-recordings bucket, five supported audio formats and 25MB cap, validate nonempty file and filename <=255; reuse SpeakingAudio with configurable accessible label and playback error. New paired nullable feedback_object_key/feedback_file_name fields; audio requires a graded submission. Teacher-only namespace feedback/<submission UUID>/<random UUID>.<ext>. Guard verifies correct submission namespace + object existence, keeps original immutable identity/attempt cap, forbids forged feedback on learner insert. New Storage policies allow staff uploads, staff read within existing submission namespace, owner read only attached feedback, staff delete only unreferenced feedback. No public media or user grade rights.

Approach: extend existing components and one testable save helper, rather than new feedback service or bucket. Selection only uses object URLs (revoked on change/close); upload starts at Save. Independent read-only design check completed, findings incorporated. User opted out of routine questions and authorized implementation, review, PR, merge and needed migrations.
